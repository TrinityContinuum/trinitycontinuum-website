# Trinity Continuum website

Independent GitHub Pages website for Trinity Continuum.

## Deployment
Upload `index.html` and `CNAME` to the root of the TrinityContinuum/trinitycontinuum-website repository, replacing the starter homepage. Existing GitHub Pages settings remain unchanged.

## 3D models
The site includes a `<model-viewer>` component. Upload an approved GLB model to `models/trinity-demo.glb` to populate the viewer. Do not publish proprietary CAD files or confidential research.

All project claims and contact information are provisional until approved by the project owner.
