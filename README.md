# Trinity Continuum website

Starter website for GitHub Pages. The public text is intentionally provisional pending Jack's approval.

## Publish
1. Create a new **public** GitHub repository called `trinitycontinuum-website`.
2. Upload `index.html`, `CNAME`, and `README.md` to the repository root.
3. In Settings > Pages choose Deploy from a branch, `main`, `/ (root)`.
4. In Settings > Pages set custom domain `trinitycontinuum.com` and save.
5. In Namecheap Advanced DNS configure four `A` records for host `@` to 185.199.108.153, 185.199.109.153, 185.199.110.153, and 185.199.111.153. Optionally add `CNAME` host `www` to YOUR_GITHUB_USERNAME.github.io (replace with actual owner).
6. After DNS propagation enable Enforce HTTPS in GitHub Pages.

Do not upload private CAD files or confidential research to a public Pages repository.
