## Revised workflow: source-first, not missing-first
1. **Located:** inspect the existing Golden Library and linked controlled sources before requesting anything from Jack.
2. **Opened:** record whether the exact PDF/Word/source can be opened with current access.
3. **Inspected:** locate the required MFG-09 drawing or engineering specification and capture its actual source page/section.
4. **Reconciled:** distinguish Rev B versus Rev A and historical versus approved design. Do not silently choose between conflicting factory dimensions or utility values.
5. **Approved:** Jack/engineering authority confirms the controlling revision and authorized bidder issue.
6. **Packaged:** create the 13-exhibit GC package and separate six-trailer technical annexes; run SHA-256 and approval checks.

The presence of a source link is evidence of **indexing**, not evidence that every embedded drawing is complete, approved or accessible. **Do not classify a document as missing until its indexed location has been checked and the access or content gap recorded.** No changes to the public website, no external release.
